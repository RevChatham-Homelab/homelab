# What is CBART?

The **Chatham Backup and Recovery Tool (CBART)** is a terminal-based application designed to automate the creation of Recovery Points for the RevChatham Homelab.

CBART is responsible for collecting, organizing, and preserving the critical information required to recover the homelab environment following hardware failure, software corruption, accidental deletion, or other disaster scenarios.

Recovery Points generated by CBART are designed to provide a complete snapshot of the operational environment by collecting items such as:

- Docker Compose configurations
- Environment file templates
- Documentation archives
- Recovery manifests
- Verification reports
- Proxmox host information
- Storage inventory
- Virtual machine inventory
- Recovery logs
- File integrity checksums

The application is designed around repeatable engineering practices, emphasizing consistency, traceability, and recoverability rather than simply creating compressed backups.
